
# Historický atlas Milovic

Digitální atlas historických míst, událostí a objektů v Milovicích,
jejich okolí a bývalém vojenském výcvikovém prostoru.

## Plánované funkce

- Interaktivní historická mapa
- Katalog historických míst a objektů
- Časová osa událostí
- Historické články a fotografie
- Evidence historických pramenů
- Administrace pro správu a publikování obsahu
- Export a zálohování dat
